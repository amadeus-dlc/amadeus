# チームメッセージングバックエンド

> 言語: [English](team-messaging.md) | **日本語**

## 廃止

Amadeus は `team-msg.sh` を同梱しません。Team Mode ランチャと同時に配布物から
消えています。

廃止した `team-msg.sh` CLI を実行しないでください。本配布に代替
トランスポートはありません。選挙 CLI は残ります。agmsg へ直接話し、
そのスクリプトは経由しません。

過去ログには `[team-msg from:<role> via:herdr machine]` 形の herdr 送信ヘッダが
残ることがあります。その接頭辞を機械注入と扱う分類器は残し、人間ターンと
取り違えないようにします。

## 関連

残るチームモード契約(`AMADEUS_OPERATING_MODE=team`)と選挙ループは
[チームモード](20-team-mode.ja.md) を参照してください。
