# Conductor Questions / 申し送り(intent 260815-rfc-autonomy-modes)

本ファイルは、ステージ固有の `*-questions.md` とは別に、intent 全体に対する conductor 宛の入力・帰属不明の入力を記録する。

## 帰属不明の入力(no-op)

- 2026-08-19 — セッション中に単独の入力 `2` を受領した。直前の裁定要求(§13 選挙 `E-260819-RFC0001-TLA-S13` の tie、選択肢 A/B/C/D)は既に監督者から **A** の回答を得て実行済みであり、`2` がその選択肢番号(= B)を指すのか別件への回答なのか帰属を確定できなかった。推測で動かず会話上で確認を求めたが追加指示がなかったため、**no-op として扱い何も実行していない**。監督者もこれを帰属不明の no-op として引き取り済み。ユーザーから別途指示があればそれに従う。

## レビュー由来のノルム修正(正規経路の不在)

- 2026-08-19 — PR #3253 の CodeRabbit 指摘(`project.md:212`、`cid:tla-authoring:c1-internal-claims-are-untrusted` の判別式)は監督者が妥当と裁定し、判別式を「再現手順を構成できるか、**または一次資料から直接検証できる証拠(スキーマ違反・不変条件違反・到達不能な遷移など)を提示できるか**」へ拡張した。
- このとき `amadeus-learnings.ts` は `surface|persist` の 2 verb のみを持ち、`persist` は同一 cid の別文言をマーカー衝突として拒否するため、**永続化済みの学習行に対するレビュー由来の文言修正を通す正規経路が存在しない**。加えて本 intent は完了済みで active-intent カーソルもクリアされており `--slug` 指定の persist 自体が成立しない。したがって直接編集を採り、その事実と根拠をここに記録する。§13 の「学習書き込みはツール経由」規則が縛るのは学習の**新規 install** であり、既存行の是正には verb が用意されていない。
